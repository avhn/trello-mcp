Trello MCP FAQ

Answers about connecting Trello to Claude, Codex and ChatGPT, choosing access policy and understanding token estimates.

What is trello-mcp?

trello-mcp is an independent, MIT-licensed Trello MCP server written in Go. It lets Model Context Protocol clients manage Trello boards, cards, checklists and attachments through a local stdio process, without a hosted intermediary.

Which clients can use this Trello MCP server?

The documented configurations cover Claude Code, Claude Desktop, Codex CLI, Codex desktop, ChatGPT desktop and OpenCode. Other clients can use local stdio transport with their own configuration format. The Codex clients and ChatGPT desktop share ~/.codex/config.toml.

How do I connect my Trello account?

Run trello-mcp auth in a terminal after installation. Create an API key manually at Trello Power-Ups administration when prompted, approve the authorization link and paste the token at the hidden terminal prompt. The command validates and saves credentials. Restart your MCP client afterward. If a release does not recognize auth, build current source or supply both environment credentials.

Are writes enabled by default?

Yes. trello-mcp auth defaults to write access: Enter at Allow write access? [Y/n] means yes. Use trello-mcp auth --read-only to request a read-only token, or TRELLO_READ_ONLY=1 to hide mutation and transfer tools. A saved read-only token cannot be upgraded by setting TRELLO_READ_ONLY=0.

Why does my client only show server_health?

Without configured credentials, the server still initializes but registers only server_health, with an account-setup hint. Run trello-mcp auth outside the MCP transport, then restart your client. A complete TRELLO_API_KEY and TRELLO_TOKEN environment pair overrides saved credentials; a partial pair is an error.

Where are credentials stored?

Credentials are saved as plaintext in trello-mcp/credentials.json under os.UserConfigDir(), honoring an absolute XDG_CONFIG_HOME override. Unix requires a private, current-user-owned 0700 directory and 0600 file. Windows relies on a private user configuration directory ACL, with type and symlink checks. Protect backups too.

Does logout revoke my Trello token?

No. trello-mcp auth logout removes the saved credential file only. It does not revoke the token at Trello, unset environment credentials or clear local selections. Revoke the token through Trello when needed, and restart your MCP client after logout.

Can I restrict access to specific workspaces?

Yes. TRELLO_ALLOWED_WORKSPACES accepts comma-separated workspace ids or canonical names, not display names. Unset means unrestricted within token permissions. The server resolves actual object ownership; supplied board ids cannot bypass the allowlist. Moves and copies check both boards.

Does it discover guest boards?

board_find searches all account boards, including guest boards visible to your token, unless workspaceId narrows the search; the optional allowlist still applies. Atlassian's documentation says its connector accesses only workspaces explicitly authorized on its consent screen. It does not establish whether guest-only boards are accessible, so no guest-board exclusion is claimed here.

Are the token savings live tokenizer measurements?

No. The README table reports estimated tokens using characters / 4 on synthetic fixtures, compared with the raw pretty-printed response style of @delorenj/mcp-server-trello 1.8.1. These are reproducible offline size estimates, not live account measurements or tokenizer counts. The tool-definition row is not a like-for-like measured comparison. Tool-call requests, protocol framing and model-specific tokenization are excluded.

Why is a tool hidden or an operation denied?

Call server_health with detail set to policy before assuming the token is broken. Tool selection, read-only mode, the workspace allowlist and platform transfer checks can refuse operations. Policy errors identify server policy; upstream HTTP 401/403 errors identify a token/permission issue. Keep server or server_health in custom TRELLO_TOOLS profiles.

Can I upload and download attachments on Windows?

Windows refuses local path uploads and attachment downloads because their ownership and path checks require Unix. Base64 uploads and URL attachments remain available when writes are enabled. On supported Unix platforms, path uploads need a dedicated TRELLO_UPLOAD_DIR. Uploads and downloads are capped at 10 MiB; no inline attachment bodies are returned.

Does read-only mode prevent every local change?

No. Read-only mode hides Trello mutations and attachment transfers, including local-file downloads, but workspace_use and board_use can still change local defaults. The server policy does not replace a suitably scoped Trello token.

Is this the official Atlassian Trello MCP connector?

No. trello-mcp is an independent Go implementation. The MIT-licensed @delorenj/mcp-server-trello 1.8.1 is the tool-coverage reference, not a runtime dependency. This project is not the Atlassian-hosted connector.
