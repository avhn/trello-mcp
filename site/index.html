Quick start: install, connect, configure

These guides follow the current source tree, including trello-mcp auth. Release availability can differ. If your binary does not recognize auth, build the current source or use a complete environment credential pair as described in the credentials guide.

1. Install on macOS or Linux

curl -fsSL https://raw.githubusercontent.com/avhn/trello-mcp/main/install.sh | sh

Installs to ~/.local/bin. Add it to your shell and MCP client's PATH, or use the full executable path.

Or install on Windows

In Windows PowerShell 5.1 or PowerShell 7:

irm https://raw.githubusercontent.com/avhn/trello-mcp/main/install.ps1 | iex

From cmd:

powershell -NoProfile -ExecutionPolicy Bypass -Command "irm https://raw.githubusercontent.com/avhn/trello-mcp/main/install.ps1 | iex"

Installs to %LOCALAPPDATA%\Programs\trello-mcp and adds the directory to your user PATH. Open a new terminal afterward. The installers verify SHA-256 checksums and do not ask for credentials.

2. Connect your Trello account

trello-mcp auth

Create an API key at Trello's Power-Ups administration page when prompted. Approve the authorization link, then paste the token at the hidden terminal prompt. Keep the link private because it contains your API key.

Write access is the default: Enter at Allow write access? [Y/n] means yes. Use trello-mcp auth --read-only for a read-only token. Credentials are validated and saved in ~/.secrets/.trello-mcp.secret, not client snippets. TRELLO_MCP_CREDENTIALS selects an absolute custom file; the complete environment key/token pair overrides files. The final fallback is ~/.secrets.env, the optional avhn/secret shared store. See the dotenv format, precedence and permission rules.

3. Add it to an MCP client

For Claude Code on a default macOS or Linux install:

claude mcp add trello --transport stdio -- "$HOME/.local/bin/trello-mcp"

For clients using generic MCP JSON, replace the path and merge this into your configuration:

{
  "mcpServers": {
    "trello": {
      "command": "/absolute/path/to/trello-mcp"
    }
  }
}

Restart your MCP client after connecting your account. See the client setup guide for Claude Desktop, Codex, ChatGPT desktop and OpenCode for paths and exact formats, or the installation guide for platform requirements.

Discover workspaces and guest boards

Account-wide discovery works across workspaces and guest boards visible to your API token, subject to the optional workspace allowlist. board_find searches account boards unless an explicit workspaceId narrows the search.

The official Atlassian connector documentation says its connector can access only workspaces explicitly authorized on its consent screen. It does not establish whether guest-only boards are accessible, so no guest-board exclusion is claimed here.

All 48 tools are available by default with credentials configured. Read-only mode exposes 19 reads and local-selection tools. Without credentials, only server_health is registered with an account-setup hint.
