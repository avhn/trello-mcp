A local Trello MCP server

Your AI assistant manages Trello boards, cards and checklists over local stdio, with compact curated responses, workspace allowlists and a read-only opt-in.

Install

curl -fsSL https://raw.githubusercontent.com/avhn/trello-mcp/main/install.sh | sh

Claude Desktop bundles support macOS and Windows amd64; Linux is beta. Download from releases and follow setup for checksums, manual updates and verification.

Or let your agent set it up

Set up trello-mcp by following https://raw.githubusercontent.com/avhn/trello-mcp/main/docs/setup.md; ask me to run its printed absolute-path auth command myself in a private terminal, then reconnect. Never capture authentication output.

You run the installer's printed auth command yourself, or fill in Claude Desktop extension settings; the agent never sees your credentials.
